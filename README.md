# ThinkPlus Education Website

A modern, responsive educational website built for **ThinkPlus Education**, showcasing courses, and providing a contact form for prospective students. The project is built using **React**, **React Router**, **Framer Motion**, and **Tailwind CSS**.

# Features
- **Home Page:** Hero section with CTA buttons, courses/services overview.
- **About Page:** Company overview, stats, and values section.
- **Courses Page:** List of courses (placeholder page can be updated dynamically).
- **Contact Page:** Contact form with "Sent successfully" confirmation message.
- **Responsive Design:** Fully responsive for mobile, tablet, and desktop.
- **Smooth Animations:** Implemented using Framer Motion.
- **Client-side Routing:** Using React Router to avoid 404 errors on Vercel/Netlify.

# Tech Stack
- **Frontend:** React.js (with functional components and hooks)  
- **Routing:** React Router DOM  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  
- **Icons:** Lucide React
